# Chapter III — Technologies & Systems

> Reliability over hype. No framework tourism or resume padding—just tools that pull their weight in production.

- **HTML Page:** https://hamzajhad.com/technologies
- **Markdown Version:** https://hamzajhad.com/technologies.md

---

## I. Languages
- **TypeScript:** Primary Full-Stack language across client interfaces and backend microservices.
- **Python:** High-speed APIs (FastAPI), data workflows, and administrative backends (Django).
- **C++:** Systems programming, algorithmic efficiency, and low-level computation.
- **Java:** Enterprise backend services and object-oriented systems.

## II. Frontend
- **React:** Interactive user interfaces and stateful application components.
- **Next.js:** Production SSR, dynamic routing, and meta-framework applications.
- **Astro:** Editorial content-first web architecture with zero-JS default output.
- **Tailwind CSS:** Ergonomic utility-first styling and robust custom design systems.

## III. Backend & Data
- **Node.js:** Asynchronous event-driven backend runtime.
- **Nest.js:** Modular TypeScript architectures with dependency injection.
- **Django:** Enterprise Python web framework for complex administrative domains.
- **FastAPI:** High-performance async Python APIs.
- **PostgreSQL:** Primary relational workhorse with ACID transactions and schema integrity.
- **Redis:** In-memory caching, pub/sub queues, and session synchronization.

## IV. Platform & Infrastructure
- **Docker:** Containerization, environment isolation, and multi-stage builds.
- **Linux:** Server administration, systemd service management, and Nginx reverse proxies.
